Government System · Network IaC · Full-Stack

Public Procurement Management System (Compras Públicas)

📌 PROBLEM

Government institutions required a transparent, secure and scalable platform to manage the full procurement lifecycle — from bid publication to contract payment — with complete auditability and role-based access control.

⚡ SOLUTION
  • Full-stack web app: PHP backend + HTML/CSS/JS frontend, MVC architecture, REST API microservices consumed by TinyLinux clients
  • Relational DB: conceptual → logical → physical design in MySQL, RBAC (Admin / Developer / Supervisor roles), prepared statements + data sanitization
  • MPLS L3VPN network: OSPF + LDP, VRF isolation per unit (COMPUBLICAS / CATERING), deployed on EVE-NG cloud (Google Cloud VM)
  • Infrastructure as Code: Ansible Playbooks in YAML (idempotent, NetDevOps) automating all PE routers via SSH v2 (AES-128, SHA-1, DH-14)
  • Security: CORS policy, Security Headers, frontend validation, server-side sanitization

02 🛡️ ISO 27001
📄 Audit Report 📄 Case Study ▶ IoT Demo
Industrial IoT · ISO 27001 Audit · Automation

QESINOR: Industrial Automation & ISO 27001 Compliance

📌 PROBLEM

Dairy manufacturing plant with manual raw material handling causing economic losses through waste and lack of traceability. No information security framework risked non-compliance with ISO standards required by buyers.

⚡ SOLUTION
  • Industrial IoT: Arduino IDE programming for automated milk cooling tank (200L) — hardware + software, low-level instruction set for multiple peripherals
  • LabVIEW integration for industrial process visualization and scalability across dairy plant dependencies
  • Remote hydraulic control via PLC integration and secure MPLS tunnels
  • Full ISMS implementation under ISO 27001:2013 — risk assessment, controls, access management, OT/IT hardening
  • Real-time compliance dashboard in Power BI with automated reporting
